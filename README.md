# Desarrollo de Aplicación React con TypeScript

Debes crear una aplicación de gestión de tareas utilizando React y TypeScript. La aplicación debe permitir a los usuarios crear, leer, actualizar y eliminar tareas. Los usuarios deben poder ver una lista de tareas, seleccionar una tarea para ver sus detalles, y editar o eliminar la tarea seleccionada. La aplicación debe ser escalable y mantener un buen rendimiento a medida que se agregan más tareas.
